# Project Information: Thai Amulet Marketplace & Real-Time Auction

## Project Overview
A web platform for Thai amulet direct sales and real-time auctions with custom styling, HTML5 canvas radar charts for spiritual status attributes, order verification, and real-time Anti-Snipe bidding backed by Firebase Firestore.

## Tech Stack
- Frontend: HTML5, Custom CSS3, Vanilla JavaScript (Fetch API & HTML5 Canvas), Firebase Client SDK (Real-Time listener)
- Backend: PHP 8+ (Native REST Client, Sessions)
- Database: Google Cloud Firebase Firestore 100% (NoSQL Collections: `categories`, `amulets`, `users`, `orders`, `auctions`, `bids`, `_meta`)
- Timezone: Asia/Bangkok (+07:00 Thailand)
- Communication: HTTP POST throughout the platform
- Color Palette:
  - Primary Dark Red: #5e030f
  - Primary Gold Accent: #E9D793
  - Dark Card Background: #45020b
  - Light Text: #ffffff
  - Dark Text: #333333
